# Rocket-Motor-Test-Stand
This project is a static test system (test stand) for rocket motors. Its primary purpose is twofold:
1. To ignite the motor safely and precisely from a distance.
2. To measure and record the thrust (force) generated by the motor in real time.

Subsystem Analysis

A. The "Brain" (ESP32)
At the heart of the system lies the ESP32 microcontroller. It acts as the computer that coordinates everything. It is powered by a separate
LiPo battery (via a Buck Converter) to ensure stability and isolation from the high currents associated with the ignition process.
• Role: Reads sensor data, stores information, and issues the ignition command.

B. Force Measurement (Load Cell & HX711)
To measure the motor's thrust, we use a load cell. The load cell converts mechanical force into a very small electrical signal.
• Since this signal is weak, an HX711 amplifier is used to convert it into a digital format that the ESP32 can read.

C. Ignition System (Two-Stage Safety)
To ignite the motor, we use a powerful 12V lead-acid battery. However, current does not flow to the igniter (e-match) unless two independent components agree:
1. The Mechanical Relay:
 Acts as the "arming safety." It is controlled by a physical key switch. As long as the key is in the "off" position, the circuit is physically broken.
 Even if the computer malfunctions, no current can flow. Turning the key "arms" the system.
2. The MOSFET: This acts as a fast-response electronic switch. Even when the system is armed (relay closed), the current is halted at the MOSFET.
Only when the ESP32 issues a digital command (via software) does the MOSFET activate, allowing the 12V current to reach the igniter.

D. Continuity Check
Before launch, we need to verify that the igniter wire is correctly connected and intact.
• The circuit includes a test button and an LED.
• Pressing the button allows a minimal, safe current (approximately 10mA) to flow through the igniter.
• If the LED lights up, it indicates that the circuit is closed and the igniter is ready. This current is too low to trigger ignition but sufficient to light the LED. 

E. Data Logging (SD Card + Wi-Fi)
All measurement data (time and force) is recorded onto a microSD card multiple times per second. 
Thus, after the test, the card can be transferred to a computer to analyze the motor's thrust curve.

 Operating Procedure
1. Startup: Power up the ESP32. The system performs a self-diagnostic check.
2. Check: If the continuity LED is lit, it indicates that the MOSFET is faulty.
3. Installation: Connect the igniter to the motor.
5. Arming: Turn the safety key. The relay engages. The system now awaits a command. Press the continuity button; if the LED lights up, the igniter is correctly connected.
6. Ignition: The ESP32 sends a command to the MOSFET. The MOSFET activates, allowing high current to flow, and the motor ignites.
7. Logging: Simultaneously, the ESP32 records values ​​from the load cell onto the SD card until combustion is complete.
